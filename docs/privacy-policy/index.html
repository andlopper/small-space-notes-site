Privacy Policy

Last updated: November 10, 2026

This policy describes this Small Space Notes website, messages sent to the brand, and the intended use of the Pinterest API to manage the brand’s own content.

Visiting this website

This is a static information website hosted on GitHub Pages. We do not provide accounts, forms, checkout or newsletter subscriptions here. The site does not install analytics, advertising tags, social embeds, tracking pixels, or its own cookies. It does not use browser local storage. Fonts and styles are loaded locally, with no external font or image services.

GitHub processes information needed to serve and secure the website. GitHub states that visitors’ IP addresses are logged and stored for security purposes, whether or not visitors are signed in to GitHub. This hosting activity is covered by the GitHub General Privacy Statement. We do not receive a visitor analytics dashboard from this site or set GitHub’s hosting-log retention periods.

Contact and privacy requests

You can contact Small Space Notes by direct message to @smallspacenotes on Instagram. Please identify your request and share only the information needed to address it. Do not send passwords or other credentials.

If you message us, we receive your account identifier, the message and any information you choose to include. We use that information to reply and handle your request. Messages remain within the messaging platform under its storage and deletion controls; this website does not copy them into a separate database. We have not established a separate fixed retention period for correspondence. You can ask us to delete correspondence within our control or raise questions about access, correction or privacy. The platform may retain its own records under its policies.

Intended Pinterest API use

Small Space Notes intends to use the Pinterest API for an internal workflow to manage its own brand content, such as publishing approved Pins and organizing its own boards, subject to Pinterest’s approval and the permissions granted. This website does not call the API, connect visitors’ Pinterest accounts or request Pinterest credentials.

The proposed integration is not implemented by this website. There is no Pinterest API data storage in the site. Before an integration starts operating, we will update this policy to describe the actual data accessed, storage, retention and service providers involved. API credentials will not be placed in this public website.

Pinterest handles information on its own platform according to the Pinterest Privacy Policy. Describing this planned use does not mean Pinterest has approved or endorsed Small Space Notes.

Sharing and other websites

We do not sell visitor or message information or share it for targeted advertising. Hosting and any messages involve the providers described above. If you follow an external link, the destination service processes information under its own policies. Social links here are ordinary links, not embedded widgets. Instagram handles messages according to its platform policies, including the Meta Privacy Policy.

Changes

We will update this page when the website or the brand’s relevant data practices change. The date above identifies the latest revision.
