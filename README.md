# Small Space Notes

A lightweight, responsive website about decorating, organization and small-space living. Built with HTML and CSS, without JavaScript, analytics, advertising tags or external assets.

## Pages

- Home: https://andlopper.github.io/small-space-notes-site/
- Privacy Policy: https://andlopper.github.io/small-space-notes-site/privacy-policy/

## Hosting

GitHub Pages publishes the `docs/` directory from the `main` branch. No build step, custom domain or additional dependencies are required. HTTPS should remain enforced in the repository's Pages settings.

## Local preview

Run `python3 -m http.server 8000 --directory docs`, then visit http://localhost:8000.

## Maintenance

Keep the privacy policy consistent with actual practices. The Pinterest integration described there is planned; update the policy before enabling any integration. Add social links only after confirming their exact brand profile URLs.
